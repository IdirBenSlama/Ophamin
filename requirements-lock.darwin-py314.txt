# Scope: this file pins every transitive dependency as installed in the
# author's working venv. Platform: **macOS arm64 + Python 3.14**. It is
# NOT portable across platforms or Python versions:
#
#   - Some pinned versions only ship macOS wheels (e.g. ``gudhi==3.12.0``
#     has no linux/arm64 Python 3.12 wheel — Docker builds fail on it).
#   - Some upstream pre-built wheels carry ABI tags that exclude Linux.
#
# The Dockerfile + CI therefore do NOT consume this lockfile. They resolve
# fresh against ``pyproject.toml`` on Python 3.12 inside Linux containers.
# This lockfile exists for the author's local dev environment and for
# *forensic* reference — given a regression, ``pip freeze`` against the
# current venv is the snapshot you compare against.
#
# To refresh after a coordinated bump:
#
#   .venv/bin/pip freeze --exclude-editable > requirements-lock.darwin-py314.txt
#
# Then re-run the full test suite + mypy --strict + coverage gate before
# committing the new pins.
#
# A *portable* lockfile (multi-platform via ``uv pip compile`` or similar)
