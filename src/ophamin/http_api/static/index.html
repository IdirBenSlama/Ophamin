The garage for building Kimera

What Ophamin has measured about Kimera

Ophamin watches Kimera run and turns what it sees into signed proofs you can re-check — no need to take anyone's word for it. The numbers up top are read live from the real proof files. Every claim below is one of those proofs; open the Proofs tab to see and re-verify each one.

The gap, in one picture

Today's memory (search / RAG) is a filing cabinet. Drop documents in; it returns the similar ones. It doesn't care what order things happened — two histories made of the same events in a different order look identical to it.

Kimera's memory is a landscape you walk. Every experience wears a permanent groove; the order of walking reshapes the land; the terrain is the memory. The same events in a different order leave different terrain.

What we proved on real data

  • ✓ Memory is permanent — once Kimera experiences something, it never erases it. (Kimera vocabulary, and again on real Enron email.)
  • ✓ Order matters — the same events in a different order leave a different memory, where a filing cabinet cannot tell them apart.
  • ✓ It separates real-risk-different histories — the same stock trades in a crash-then-recover vs rise-then-fall order: retrieval sees them as identical; Kimera tells them apart, every time. (Real S&P 500.)

What we did not prove (stated plainly)

Kimera can tell two histories apart, but it cannot yet say how much riskier one is — a "spot-the-difference" tool, not a "measure-the-size" tool. We searched all ~4,000 of Kimera's live signals for one that measures size; none held up on independent data. That's a wiring gap (the readout isn't switched on yet), not a dead end — about 13% of Kimera is wired so far.
